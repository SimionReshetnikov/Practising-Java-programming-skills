# Java Multithreading Practice

## Задание 1: Имитация загрузки файлов (Thread + Runnable)

### Описание
Создать программу, которая имитирует загрузку нескольких файлов из интернета. Каждый файл загружается в отдельном потоке.

### Требования
- Класс `FileDownloader` реализует `Runnable`
- Каждую секунду выводить прогресс загрузки
- После завершения вывести сообщение об успешной загрузке
- В `main` запустить несколько потоков с разными файлами

## Задание 2: Обработка очереди заказов (ExecutorService)

### Описание
Создать систему обработки заказов интернет-магазина с использованием пула потоков.

### Требования
- Класс `Order` — модель заказа (ID, имя клиента, время обработки)
- В `main` создать `ExecutorService` с фиксированным пулом потоков
- Отправить несколько заказов на выполнение
- Использовать `shutdown()` и `awaitTermination()` для корректного завершения
