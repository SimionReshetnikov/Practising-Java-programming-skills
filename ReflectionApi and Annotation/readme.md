# Задание 1: Анализатор методов 
Описание
Написать программу, которая анализирует любой класс и выводит информацию о его методах.

Что нужно сделать
Создать метод, который принимает объект Class<?> и выводит:

Имя класса

Все публичные методы с их возвращаемыми типами и параметрами

Все приватные методы (только имена)

Продемонстрировать работу на классе String и на своем классе (например, Person с полями и методами)

# Задание 2: Создание объекта через рефлексию
Описание
Написать программу, которая создает объект класса через рефлексию и вызывает его методы.

Что нужно сделать
Создать класс User с полями: name, age, email

Конструктор с параметрами (name, age, email) и пустой конструктор

Методы: displayInfo() — выводит информацию о пользователе

В main с помощью рефлексии:

Найти конструктор с параметрами

Создать объект через рефлексию

Вызвать метод displayInfo() через рефлексию

Создать объект через пустой конструктор и установить поля через рефлексию

# Задание 3: Своя аннотация 
Описание
Создать свою аннотацию и обработать её через рефлексию.

Что нужно сделать
Создать аннотацию @Important с полем level (int, по умолчанию 1)

Создать аннотацию @Deprecated (можно использовать встроенную)

Создать класс с несколькими методами, часть пометить @Important, часть @Deprecated

Написать метод, который через рефлексию:

Находит все методы с @Important

Выводит их имена и уровень важности

Находит методы с @Deprecated и выводит предупреждение
