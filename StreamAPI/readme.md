# Практические задания на тему StreamAPI в Java
# Задание 1
Создать массив строк (10-20 слов, с повторениями). Выполнить следующие операции, используя Stream API:

1. Найти и вывести список уникальных слов (без дубликатов)

2. Подсчитать, сколько раз встречается каждое слово

3. Найти и вывести самое длинное слово

4. Отсортировать слова по алфавиту и вывести

5. Отфильтровать слова длиной больше 3 символов и вывести

# Задание 2

Реализовать класс PhoneDirectory, который:

1. Хранит список фамилий и телефонных номеров (одна фамилия может иметь несколько номеров)

2. Метод add(String lastName, String phoneNumber) — добавляет номер для указанной фамилии

3. Метод get(String lastName) — возвращает список всех номеров для указанной фамилии

4. Метод getAll() — возвращает список всех записей (фамилия + номер)

Сделать это без использования Stream API. Потом — рефакторинг с Stream (Пункт 2).

# Задание 3
Создать список целых чисел (15-20 элементов, включая отрицательные). С помощью Stream API:

1. Найти сумму всех положительных чисел
   
2. Найти количество отрицательных чисел
   
3. Найти максимальное четное число
   
4. Получить список квадратов всех чисел
   
5. Отфильтровать числа, которые делятся на 3, и вывести

# Задание 4
Создать класс Student с полями: name, grade (оценка от 2 до 5), faculty (факультет). Создать список студентов (10-15 человек).

С помощью Stream API:

1. Получить список студентов с оценкой выше 4

2. Сгруппировать студентов по факультету

3. Для каждого факультета посчитать среднюю оценку

4. Найти студента с максимальной оценкой
